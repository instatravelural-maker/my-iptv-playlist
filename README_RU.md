# Единый IPTV-плейлист для OTTPlayer

Этот репозиторий собирает один файл `playlist.m3u` из публичных плейлистов проекта iptv-org. Скрипт переносит в итоговый файл реальные записи каналов (а не ссылки на другие M3U), назначает русские группы и удаляет повторяющиеся URL внутри каждой группы.

## Группы

- Россия
- Беларусь и Казахстан
- Кино
- Спорт
- Новости
- Музыка
- Детские
- Познавательные (документальные, образовательные и научные)
- Региональные (ручное добавление собственных публично доступных потоков через `regional.m3u`)

## Важно

- Это сборник ссылок на публично доступные потоки, а не гарантия их работоспособности.
- Канал может не открываться из-за геоблокировки, ограничений вещателя, отключённого потока или временного сбоя.
- Категорийные мировые списки могут включать каналы на разных языках. Названия групп в OTTPlayer — это тематическая сортировка, не обещание русского языка вещания.
- Не добавляйте ссылки на платные/закрытые трансляции без разрешения правообладателя.
- `regional.m3u` изначально пустой. Добавляйте туда только реальные ссылки на разрешённые потоки.

## Как разместить на GitHub (без терминала)

1. Войдите на https://github.com/ или создайте бесплатный аккаунт.
2. Нажмите `+` в правом верхнем углу → `New repository`.
3. Название: `my-iptv-playlist`. Выберите `Public`, затем `Create repository`.
4. Загрузите файлы и папку из этого архива, сохранив структуру:
   - `build_playlist.py`
   - `regional.m3u`
   - `README_RU.md`
   - `.github/workflows/update-playlist.yml`
5. На странице репозитория откройте вкладку `Actions`. Если GitHub спросит, разрешите запуск Actions.
6. Откройте workflow `Build IPTV playlist` и нажмите `Run workflow`.
7. Дождитесь зелёной галочки. Скрипт создаст `playlist.m3u` в корне репозитория.
8. Скопируйте ссылку на сырой файл: откройте `playlist.m3u` → `Raw`. Адрес должен выглядеть так:
   `https://raw.githubusercontent.com/ВАШ_ЛОГИН/my-iptv-playlist/main/playlist.m3u`
9. Добавьте этот URL в OTTPlayer как URL плейлиста.

После первого запуска GitHub Actions будет обновлять файл ежедневно. Если измените `build_playlist.py` или `regional.m3u`, он также запустится после сохранения изменений.

## Региональные каналы

Откройте `regional.m3u` → Edit (карандаш). Удалите примерные строки и добавляйте каналы парами строк:

```m3u
#EXTINF:-1 tvg-name="Название канала" group-title="Региональные",Название канала
https://адрес-потока/stream.m3u8
```

Нажмите `Commit changes`. После запуска Actions канал попадёт в итоговый плейлист.
