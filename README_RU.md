# Единый IPTV-плейлист для OTTPlayer

Этот репозиторий собирает один файл `playlist.m3u` из публичных плейлистов проекта iptv-org. Скрипт переносит в итоговый файл реальные записи каналов (а не ссылки на другие M3U), назначает русские группы и удаляет повторяющиеся URL внутри каждой группы.

## Группы

- Федеральные: Первый, Россия 1/24/К, Матч ТВ, НТВ, Пятый, ТВ Центр, РЕН ТВ, Спас, СТС, Домашний, ТВ-3, Пятница!, Звезда, Мир, ТНТ, Муз-ТВ, Карусель, ОТР, Ю, Суббота!, Че, 2х2, Солнце, РБК, RT и др., включая их международные версии
- Общие, Региональные, Беларусь, СНГ и зарубежье
- Новости, Кино, Сериалы, Спорт, Детские, Развлекательные, Познавательные, Кулинария и другие тематические группы
- Музыка по жанрам (`Музыка | Рок`, `Музыка | Ретро`, `Музыка | Шансон`, `Музыка | Фолк и народная`…) и по регионам для зарубежных (`Музыка | Латино`, `Музыка | Европейская`, `Музыка | Индия и Южная Азия`…)
- Не проверено: потоки из iptv-org и Free-TV, которые при проверке из GitHub Actions (США) ответили как при геоблокировке (403, таймаут и т.п.). Из России они могут работать; при каждой сборке проверяются заново
- Региональные (ручное добавление собственных публично доступных потоков через `regional.m3u`)
- Для взрослых (только из отдельного файла `adult.m3u`, если он есть)

## Важно

- Это сборник ссылок на публично доступные потоки, а не гарантия их работоспособности.
- Канал может не открываться из-за геоблокировки, ограничений вещателя, отключённого потока или временного сбоя.
- Категорийные мировые списки могут включать каналы на разных языках. Названия групп в OTTPlayer — это тематическая сортировка, не обещание русского языка вещания.
- Не добавляйте ссылки на платные/закрытые трансляции без разрешения правообладателя.
- `regional.m3u` изначально пустой. Добавляйте туда только реальные ссылки на разрешённые потоки.

## Как собирается плейлист

- Источники: каталог iptv-org (основной), публичный список официальных бесплатных потоков [Free-TV/IPTV](https://github.com/Free-TV/IPTV) (только группы Russia и Belarus) и публичные сборники [ngrch/iptv](https://github.com/ngrch/iptv) и [gdydg/iptv](https://github.com/gdydg/iptv). Из сборников не берутся кинозалы, ретрансляции платных пакетов операторов и ссылки с токенами/подписями; добавляются только ссылки, прошедшие проверку.
- Телепрограмма (EPG): в заголовке плейлиста указан `url-tvg` бесплатной программы iptvx.one; `tvg-id` каналов сопоставляется с ней по названию.
- Язык: если у потока нет описания языка, он сохраняется, когда сам канал отмечен в каталоге как российский или другая версия канала вещает на русском.
- Музыкальные каналы сохраняются независимо от языка и делятся по жанрам (`Музыка | Рок`, `Музыка | Ретро` и т.д.).
- Группы назначаются по названию канала: Discovery, Animal Planet, National Geographic, History, TLC, Travel Channel и подобные → «Познавательные»; отдельно «Кино», «Сериалы», «Спорт», «Новости», «Детские», «Развлекательные».
- Каналы Казахстана и Украины, а также их казахстанские/украинские версии исключаются.
- SD/HD/Full HD/4K-версии сохраняются как отдельные записи с пометкой качества.
- Все ссылки проверяются HTTP-запросом из GitHub Actions (США). Не ответившие перепроверяются с узлов бесплатного сервиса [check-host.net](https://check-host.net) в Москве (до `RU_CHECK_LIMIT`=120 за сборку, сначала федеральные и международные русскоязычные; у сервиса есть лимит запросов). Существующие записи удаляются, только если поток не работает и из России (404, нет домена). Новые ссылки: мёртвые (404, нет домена, страница вместо потока) не добавляются, похожие на геоблок из iptv-org/Free-TV попадают в «Не проверено». Проверка выполняется с серверов в США, поэтому часть российских потоков с геоблокировкой может не пройти её. Отключить проверку: переменная окружения `CHECK_NEW_STREAMS=0`.
- Ссылки с параметрами `token=`, `sign=` и т.п. из сборников не берутся. В каталоге iptv-org есть публичные ссылки с общими (не персональными) токенами — например `fs.uplink.kz/...?token=onlinetv`, подписанные ссылки smotrim и rutube из их плееров; они сохраняются.
- Защита: если каналов меньше 100 или меньше 60% от прошлой версии, либо файл получился некорректным, `playlist.m3u` не перезаписывается.
- «Для взрослых»: отдельная группа берётся только из файла `adult.m3u` (если вы его создадите) и не смешивается с обычными каналами. Добавляйте туда только разрешённые публичные потоки. Не добавляйте в репозиторий персональные ссылки и ключи доступа из чужих плейлистов.

## Как разместить на GitHub (без терминала)

1. Войдите на https://github.com/ или создайте бесплатный аккаунт.
2. Нажмите `+` в правом верхнем углу → `New repository`.
3. Название: `my-iptv-playlist`. Выберите `Public`, затем `Create repository`.
4. Загрузите файлы и папку из этого архива, сохранив структуру:
   - `build_playlist.py`
   - `regional.m3u`
   - `README_RU.md`
   - `.github/workflows/update-playlist.yml`
5. На странице репозитория откройте вкладку `Actions`. Если GitHub спросит, разрешите запуск Actions.
6. Откройте workflow `Build IPTV playlist` и нажмите `Run workflow`.
7. Дождитесь зелёной галочки. Скрипт создаст `playlist.m3u` в корне репозитория.
8. Скопируйте ссылку на сырой файл: откройте `playlist.m3u` → `Raw`. Адрес должен выглядеть так:
   `https://raw.githubusercontent.com/ВАШ_ЛОГИН/my-iptv-playlist/main/playlist.m3u`
9. Добавьте этот URL в OTTPlayer как URL плейлиста.

После первого запуска GitHub Actions будет обновлять файл ежедневно. Если измените `build_playlist.py` или `regional.m3u`, он также запустится после сохранения изменений.

## Региональные каналы

Откройте `regional.m3u` → Edit (карандаш). Удалите примерные строки и добавляйте каналы парами строк:

```m3u
#EXTINF:-1 tvg-name="Название канала" group-title="Региональные",Название канала
https://адрес-потока/stream.m3u8
```

Нажмите `Commit changes`. После запуска Actions канал попадёт в итоговый плейлист.
